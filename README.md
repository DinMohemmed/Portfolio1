## 🛠 Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Flexbox, Grid, keyframe animations
- **Google Fonts** — Poppins (body) + Fira Code (tech badges)
- **GitHub API** — Avatar loaded directly from GitHub CDN
